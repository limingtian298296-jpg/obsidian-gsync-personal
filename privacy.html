Privacy Policy

Last updated: October 26, 2026

Purpose

This OAuth client is used by its owner with the GSync Obsidian plugin to synchronize personal notes and attachments with Google Drive.

Google user data

The GSync plugin uses the Google Drive API to list, read, upload, update, and move to trash files within the Google Drive folder configured by the user. Data is transferred directly between the user's devices and Google's API. This personal website does not operate a data-processing server.

Storage and sharing

According to the plugin documentation, OAuth credentials and refresh tokens are stored locally in the plugin's configuration file on each device. They should not be shared or published. This personal setup does not sell Google user data or use it for advertising.

Third parties

Google processes account data and stores files according to Google's own applicable policies. This website does not provide a separate cloud storage or data-processing service.

Revoking access

The owner can revoke this application's access through Google Account security settings.
